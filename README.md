# CtrlSpendings

An Avalonia/C# demo showing how to asrchitect an app with basic patterns like MVC.

There's also an NClass diagram available in the root directory.

## Build

It can be built using the usual mechanisms, such as:

```sh
$ cd CtrlSpendings
$ dotnet build
```

## Execution

It can be run using the usual mechanisms, such as:

```sh
$ cd CtrlSpendings
$ dotnet run
```

NOTE: This app was coded against .NET 10, in case another, more recent version is needed, then the file `CtrlSpendings/CtrlSpendings.csproj` should be updated accordingly.
